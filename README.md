# Gestion de Produits - Application Spring Boot

## Description

Cette application permet de gérer une liste de produits à travers une interface REST. Elle utilise une base de données en mémoire pour stocker les données.

## Fonctionnalités principales

- ➕ Ajouter un produit
- 📋 Afficher tous les produits
- 🔍 Consulter un produit par son identifiant
- 🔎 Rechercher des produits par nom
- ✏️ Mettre à jour un produit
- 🗑️ Supprimer un produit

## Outils utilisés

- Spring Boot
- Base de données H2 (en mémoire)
- Spring Data JPA
- Spring Web
